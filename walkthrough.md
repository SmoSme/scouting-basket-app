# Guida Collegamento Supabase, Resilienza Offline & Deploy su Vercel

L'applicazione **Courtside Pro Basketball Analytics** è stata integrata con **Supabase** per il salvataggio dei dati in cloud ed un sistema di **Resilienza Offline-First** per garantire che nessun dato vada perso se il Wi-Fi del palazzetto salta durante la partita.

## 🗄️ 1. Creazione della Tabella su Supabase (SQL Query)

Prima di avviare l'app, apri il **SQL Editor** del tuo progetto Supabase ed esegui questa query per creare la tabella `scouting_log`:

```sql
CREATE TABLE IF NOT EXISTS scouting_log (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  timestamp TEXT,
  quarto TEXT NOT NULL,
  numero TEXT NOT NULL,
  giocatore TEXT NOT NULL,
  azione TEXT NOT NULL,
  categoria TEXT NOT NULL,
  zona TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Abilita l'accesso in lettura/scrittura per la chiave anonima
ALTER TABLE scouting_log ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Consenti inserimento pubblico per scouting_log"
ON scouting_log FOR INSERT WITH CHECK (true);

CREATE POLICY "Consenti lettura pubblica per scouting_log"
ON scouting_log FOR SELECT USING (true);
```

## ⚡ 2. Come Funziona la Resilienza Offline

1. **Quando sei Online (Wi-Fi attivo)**:
   - Ad ogni azione registrata, l'interfaccia si aggiorna in **<5ms (latenza zero)** e l'azione viene salvata direttamente nella tabella `scouting_log` di Supabase.
2. **Se il Wi-Fi del palazzetto salta (Offline)**:
   - L'app rileva lo stato offline ed inserisce l'evento in una coda locale in `localStorage` (`scouting_offline_queue`).
   - Nella barra in alto compare il badge **`📦 X IN CODA (SYNC)`** e la notifica *“Salvato offline (in coda sync Wi-Fi)”*.
3. **Ripristino Connessione**:
   - Appena il tablet o laptop si riconnette al Wi-Fi o 4G/5G, il listener `window.addEventListener('online')` invia **automaticamente** in blocco tutti gli eventi accumulati a Supabase e svuota la coda locale.

## 🚀 3. Guida al Deploy su Vercel Passo-Passo

### Metodo A: Tramite GitHub + Vercel Dashboard (Consigliato)

1. **Carica il progetto su GitHub**:
   ```bash
   git add .
   git commit -m "Integrato Supabase e resilienza offline per Vercel deploy"
   git push origin main
   ```
2. **Collega il repository a Vercel**:
   - Accedi a [Vercel.com](https://vercel.com) e clicca su **Add New ➔ Project**.
   - Seleziona il tuo repository GitHub `BBA Statistics App`.
3. **Configura le Variabili d'Ambiente su Vercel**:
   Nella schermata di configurazione prima di cliccare su *Deploy*, espandi la sezione **Environment Variables** ed inserisci:

   | Key | Value |
   | :--- | :--- |
   | `VITE_SUPABASE_URL` | `https://tuo-id-progetto.supabase.co` |
   | `VITE_SUPABASE_ANON_KEY` | `eyJhbGciOiJIUzI1NiIsInR5cCI6...` |

4. Clicca su **Deploy**. In pochi secondi Vercel ti fornirà il tuo link pubblico sicuro HTTPS (es. `https://bba-statistics-app.vercel.app`).

---

### Metodo B: Tramite Vercel CLI (Da Terminale)

```bash
# 1. Installa Vercel CLI se non ce l'hai
npm install -g vercel

# 2. Avvia il deploy
vercel

# 3. Imposta le variabili d'ambiente su Vercel via CLI
vercel env add VITE_SUPABASE_URL
vercel env add VITE_SUPABASE_ANON_KEY

# 4. Deploy di produzione finale
vercel --prod
```
